# Hotel Booking - Data Analysis using Python

This project analyzes hotel booking data to uncover patterns related to cancellations, customer behavior, and booking trends. The analysis is performed using Python and popular data manipulation and visualization libraries.

## 🎯 Objectives

- Clean and preprocess hotel booking data.
- Analyze cancellation patterns and identify key factors.
- Explore customer demographics and booking behaviors.
- Visualize trends in booking lead times, stay durations, and more.

## 🗂️ Dataset

The dataset contains booking information for a city hotel and a resort hotel, including:

- Booking dates and lead times
- Customer demographics (e.g., country, number of guests)
- Booking details (e.g., room type, meal plan)
- Cancellation status
- Special requests and other relevant features

Link to dataset: [Hotel Booking Dataset](https://www.kaggle.com/code/sharliznabil/hotel-booking)

## 🛠️ Tools & Libraries

- Python
- Pandas
- Numpy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Analyses

- **Cancellation Analysis:** Identified factors contributing to booking cancellations, such as lead time and special requests.
- **Customer Behavior:** Examined booking patterns based on customer demographics and preferences.
- **Booking Trends:** Analyzed seasonal trends, average stay durations, and booking lead times.

## 📈 Visualizations

- Heatmaps showing correlations between features
- Bar charts depicting cancellation rates across different categories
- Line plots illustrating booking trends over time

## 📌 Sample Insights

- Longer lead times are associated with higher cancellation rates.
- Customers with special requests are less likely to cancel.
- Resort hotels experience higher cancellation rates compared to city hotels.
